# Markdown renderer
Dependency-free Markdown renderer.

Exports `parse(markdown)` from `parse.js` as a dependency-free ES module.
Run `node main.ts` to read `/input/cases.json` and write `/output/html.json`.

Validation: all 720 supplied practice cases match the marked 18.1.3 reference byte for byte.
